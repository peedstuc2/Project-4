# Project 4 — Python Simulations

## Goal
Learn Python by building simulations from the ground up, starting with simple mechanical systems and gradually progressing to complex vehicles and aircraft.

## First Simulation: Rotating Wheel

### Objective
Create a 2D simulation of a wheel that rotates when a force is applied.

### Learning Goals
- Understand force and rotation.
- Learn how to represent movement using Python.
- Observe how applied force affects a wheel's rotation.
- Build, test, and improve simulations incrementally.

## Future Direction
Gradually expand the project to include axles, carts, engines, vehicles, and eventually aircraft, while developing the skills needed to build a Python-based simulation engine.
